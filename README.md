# poke_jlopz_app

App **pública** para mostrar Pokémons, **multiplataforma** para **Android** e **iOS**, creada con **Flutter**.

## Plataformas soportadas

- Android
- iOS

## Requisitos

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- Android Studio / Xcode para ejecutar en emulador o dispositivo

## Cómo ejecutar

```bash
flutter pub get
flutter run
```

## Ramas

- `develop`: rama de desarrollo
